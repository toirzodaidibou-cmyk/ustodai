# UstodAI — нақшаи проект

## Идея
Омӯзгори AI, ки забонҳои хориҷиро **бо забони тоҷикӣ** меомӯзонад. Се усули илмӣ дар асоси он ҳастанд:
1. **Такрори фосилавӣ (FSRS)**: калима маҳз пеш аз фаромӯш шуданаш такрор мешавад.
2. **Эффекти санҷиш**: корбар калимаро на танҳо мехонад, балки аз хотира ба ёд меорад.
3. **Мнемоникаи AI (усули калимаи калидӣ)**: калимаи хориҷӣ ба калимаи ҳамсадои тоҷикӣ ва тасвир пайваст мешавад.

Илова бар ин, ҳар рӯз як масъалаи мантиқӣ дода мешавад ва корбар харитаи пешрафти худро мебинад.

## Принсипҳо
- Аввал **як забон (тоҷикӣ → англисӣ)** пурра сохта мешавад, баъд забонҳои дигар.
- Ваъдаҳои бе исбот, рақамҳои сохта ва шарҳҳои қалбакӣ манъ аст. Ҳамаи рақамҳо аз маълумоти воқеӣ гирифта мешаванд.
- Ҷаласаи ҳаррӯза ≤ 15 дақиқа. Корбар бояд якбора ба омӯзиш гузарад, то бақайдгирӣ омӯзишро таъхир надиҳад.
- Сайт дар телефон ва компютер кор мекунад, PWA мешавад ва мавзӯи равшан ва торик дорад.

## Stack
| Қисм | Технология |
|---|---|
| Frontend ва backend | Next.js 16 (App Router, Server Actions), React 19, TypeScript |
| Дизайн | Tailwind CSS v4, токенҳои ранг, шрифти Inter (cyrillic-ext), Fluent Emoji 3D (MIT) |
| Пойгоҳи додаҳо | Lakebase Postgres 18 дар Neon (Frankfurt), Drizzle ORM, драйвери `pg` |
| Такрори фосилавӣ | `ts-fsrs` (FSRS-6) |
| AI | Claude API: мнемоника, шарҳи грамматика, гуфтугӯ |
| Овоз | Web Speech API (TTS), баъдтар STT барои санҷиши талаффуз |
